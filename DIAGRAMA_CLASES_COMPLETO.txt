MÉTODOS escribirDisco() y leerDisco():
───────────────────────────────────────────────────────────────────────────
Presentes en TODAS las clases de entidad (Socio, Actividad, Cancha, etc.)

• escribirDisco(pos: int): bool
  - Permite que el objeto se escriba a sí mismo en el archivo binario
  - Parámetro: posición donde se guardará el objeto
  - Retorna: true si se guardó correctamente, false en caso contrario
  - Usa: fopen("archivo.dat", "rb+"), fseek(), fwrite()

• leerDisco(pos: int): bool
  - Permite que el objeto se lea a sí mismo desde el archivo binario
  - Parámetro: posición desde donde se leerá el objeto
  - Retorna: true si se leyó correctamente, false en caso contrario
  - Usa: fopen("archivo.dat", "rb"), fseek(), fread()

MÉTODOS DE LAS CLASES ARCHIVO:
───────────────────────────────────────────────────────────────────────────
Presentes en TODAS las clases Archivo (ArchivoSocio, ArchivoActividad, etc.)

• guardar(objeto): bool
  - Agrega un nuevo objeto al final del archivo
  - Usa: fopen("archivo.dat", "ab"), fwrite()

• leer(pos: int): Objeto
  - Lee un objeto desde una posición específica
  - Usa: fopen("archivo.dat", "rb"), fseek(), fread()

• contarRegistros(): int
  - Cuenta cuántos objetos hay en el archivo
  - Usa: fseek(SEEK_END), ftell()

• modificar(objeto, pos: int): bool
  - Modifica un objeto en una posición específica
  - Usa: fopen("archivo.dat", "rb+"), fseek(), fwrite()
