PREGUNTA DEL PROFESOR:
"¿Para qué se usan los métodos leerDisco() y escribirDisco()?"

RESPUESTA:
───────────────────────────────────────────────────────────────────────────

Estos métodos implementan el patrón de PERSISTENCIA ORIENTADA A OBJETOS,
permitiendo que cada objeto sea responsable de su propia serialización.

MÉTODO: escribirDisco(pos: int): bool
───────────────────────────────────────────────────────────────────────────
PROPÓSITO:
  Permite que un objeto se escriba a sí mismo en el archivo binario en
  una posición específica.

FUNCIONAMIENTO:
  1. Abre el archivo en modo lectura/escritura binaria ("rb+")
  2. Se posiciona en la ubicación indicada usando fseek()
  3. Escribe el objeto completo usando fwrite(this, ...)
  4. Cierra el archivo
  5. Retorna true si tuvo éxito, false si falló

EJEMPLO DE USO:
  Socio socio;
  socio.setNumeroSocio(1);
  socio.setNombre("Juan");
  socio.escribirDisco(0);  // Guarda en posición 0

VENTAJAS:
  • El objeto se guarda a sí mismo (encapsulamiento)
  • Acceso directo por posición (eficiente)
  • Código más limpio y orientado a objetos

───────────────────────────────────────────────────────────────────────────

MÉTODO: leerDisco(pos: int): bool
───────────────────────────────────────────────────────────────────────────
PROPÓSITO:
  Permite que un objeto se cargue a sí mismo desde el archivo binario
  desde una posición específica.

FUNCIONAMIENTO:
  1. Abre el archivo en modo lectura binaria ("rb")
  2. Se posiciona en la ubicación indicada usando fseek()
  3. Lee los datos y los carga en el objeto usando fread(this, ...)
  4. Cierra el archivo
  5. Retorna true si tuvo éxito, false si falló

EJEMPLO DE USO:
  Socio socio;
  socio.leerDisco(0);  // Carga desde posición 0
  cout << socio.getNombre();  // Muestra "Juan"

VENTAJAS:
  • El objeto se carga a sí mismo (encapsulamiento)
  • Acceso directo por posición (eficiente)
  • No necesita crear objetos auxiliares

═══════════════════════════════════════════════════════════════════════════
  DIFERENCIA ENTRE MÉTODOS DE ENTIDAD Y MÉTODOS DE ARCHIVO
═══════════════════════════════════════════════════════════════════════════

MÉTODOS DE CLASES DE ENTIDAD (escribirDisco/leerDisco):
───────────────────────────────────────────────────────────────────────────
• El OBJETO se persiste a sí mismo
• Responsabilidad: La clase de entidad
• Uso: Cuando el objeto ya existe y quiere guardarse/cargarse
• Ejemplo:
    Socio s;
    s.setNombre("Juan");
    s.escribirDisco(0);  // El socio se guarda a sí mismo

MÉTODOS DE CLASES ARCHIVO (guardar/leer/modificar):
───────────────────────────────────────────────────────────────────────────
• Una clase EXTERNA gestiona la persistencia
• Responsabilidad: La clase Archivo
• Uso: Operaciones CRUD completas sobre el archivo
• Ejemplo:
    ArchivoSocio archivo;
    Socio s;
    s.setNombre("Juan");
    archivo.guardar(s);  // El archivo guarda al socio
    
    Socio s2 = archivo.leer(0);  // El archivo lee un socio

AMBOS ENFOQUES SON COMPLEMENTARIOS:
───────────────────────────────────────────────────────────────────────────
• escribirDisco/leerDisco: Para operaciones simples y directas
• Clases Archivo: Para operaciones complejas (búsquedas, conteos, etc.)
