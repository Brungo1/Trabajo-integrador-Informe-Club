═══════════════════════════════════════════════════════════════════════════
  DECISIÓN DE DISEÑO: SISTEMA DE PERSISTENCIA
═══════════════════════════════════════════════════════════════════════════

Optamos por CENTRALIZAR toda la gestión de persistencia en las clases
Archivo (ArchivoSocio, ArchivoActividad, etc.) para mantener una 
responsabilidad única y evitar duplicación de código.

Las clases de entidad solo contienen:
  • Atributos privados
  • Getters y Setters
  • Constructor

La persistencia es manejada exclusivamente por las clases Archivo.

═══════════════════════════════════════════════════════════════════════════
  CLASES ARCHIVO - GESTIÓN DE PERSISTENCIA
═══════════════════════════════════════════════════════════════════════════

Cada clase Archivo proporciona métodos completos para:

• guardar(objeto): bool
  └─ Agrega un nuevo registro al final del archivo
  └─ Usa: fopen("archivo.dat", "ab"), fwrite()

• leer(pos: int): Objeto
  └─ Lee un registro desde una posición específica
  └─ Usa: fopen("archivo.dat", "rb"), fseek(), fread()

• modificar(objeto, pos: int): bool
  └─ Actualiza un registro en una posición específica
  └─ Usa: fopen("archivo.dat", "rb+"), fseek(), fwrite()

• contarRegistros(): int
  └─ Retorna la cantidad total de registros
  └─ Usa: fseek(SEEK_END), ftell()

• buscar...(): int (solo en ArchivoSocio)
  └─ Métodos de búsqueda específicos
  └─ buscarPorNumero(int): int
  └─ buscarPorDni(int): int

EJEMPLO DE USO:
───────────────────────────────────────────────────────────────────────────
    ArchivoSocio archivo;
    Socio socio;
    
    // Configurar datos usando setters
    socio.setNumeroSocio(1);
    socio.setDni(12345678);
    socio.setNombre("Juan");
    socio.setApellido("Pérez");
    
    // Guardar usando clase Archivo
    if (archivo.guardar(socio)) {
        cout << "Socio guardado exitosamente" << endl;
    }
    
    // Leer usando clase Archivo
    Socio s = archivo.leer(0);
    cout << "Nombre: " << s.getNombre() << endl;
    
    // Modificar
    s.setTelefono("123456");
    archivo.modificar(s, 0);
    
    // Buscar
    int pos = archivo.buscarPorDni(12345678);

  TECNOLOGÍAS Y TÉCNICAS UTILIZADAS
═══════════════════════════════════════════════════════════════════════════

LENGUAJE: C++
PARADIGMA: Programación Orientada a Objetos (POO)
COMPILADOR: Clang++

TÉCNICAS DE POO APLICADAS:
  ✓ Encapsulamiento (atributos privados, métodos públicos)
  ✓ Abstracción (clases representan entidades del mundo real)
  ✓ Modularización (separación en archivos .h)
  ✓ Reutilización (clase Fecha usada en múltiples clases)
  ✓ Responsabilidad única (persistencia centralizada)

PERSISTENCIA:
  ✓ Archivos binarios (.dat)
  ✓ Funciones: fopen, fclose, fread, fwrite, fseek, ftell
  ✓ Modos: "rb" (lectura), "rb+" (lectura/escritura), "ab" (append)
  ✓ Acceso directo por posición

INTERFAZ:
  ✓ Librería rlutil.h para colores y utilidades de consola
  ✓ Menús interactivos con navegación

CONTROL DE VERSIONES:
