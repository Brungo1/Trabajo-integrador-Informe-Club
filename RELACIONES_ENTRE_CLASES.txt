📌 TIPOS DE RELACIONES:
───────────────────────────────────────────────────────────────────────────
1. COMPOSICIÓN (◆────): Una clase contiene a otra como atributo
2. ASOCIACIÓN (────): Una clase usa/referencia a otra
3. DEPENDENCIA (- - ->): Una clase depende de otra para funcionar
4. GESTIÓN (⟨manages⟩): Una clase Archivo gestiona una clase Entidad

CLASES ARCHIVO (ArchivoSocio, ArchivoActividad, etc.)
───────────────────────────────────────────────────────────────────────────
GESTIONAN:
  • Cada clase Archivo gestiona UNA clase de entidad específica

RELACIÓN:
  • 1:1 (Una clase Archivo por cada clase de Entidad)

DEPENDENCIA:
  • Dependen de la clase de entidad que gestionan
  • Usan los métodos escribirDisco/leerDisco de las entidades

═══════════════════════════════════════════════════════════════════════════
  CLASES ASOCIATIVAS (Relaciones Muchos a Muchos)
═══════════════════════════════════════════════════════════════════════════

1. INSCRIPCION
   └─ Relaciona: Socio ←→ Actividad
   └─ Permite: Un socio puede inscribirse en muchas actividades
               Una actividad puede tener muchos socios inscritos
   └─ Cardinalidad: N:M (Muchos a Muchos)

2. ASISTENCIA
   └─ Relaciona: Socio ←→ Actividad
   └─ Permite: Un socio puede asistir a muchas actividades
               Una actividad puede tener muchos socios asistentes
   └─ Cardinalidad: N:M (Muchos a Muchos)

═══════════════════════════════════════════════════════════════════════════
  DEPENDENCIAS INDIRECTAS
═══════════════════════════════════════════════════════════════════════════

Para realizar operaciones completas, algunas clases necesitan consultar
otras clases a través de sus archivos:

EJEMPLO 1: Listar reservas de un socio
───────────────────────────────────────────────────────────────────────────
  ArchivoReserva → lee todas las reservas
       ↓
  Filtra por NumeroSocio
       ↓
  ArchivoSocio → obtiene datos del socio
       ↓
  ArchivoCancha → obtiene datos de la cancha

EJEMPLO 2: Listar inscripciones de una actividad
───────────────────────────────────────────────────────────────────────────
  ArchivoInscripcion → lee todas las inscripciones
       ↓
  Filtra por NumeroActividad
       ↓
  ArchivoSocio → obtiene datos de cada socio inscrito

EJEMPLO 3: Registrar un pago
───────────────────────────────────────────────────────────────────────────
  ArchivoPago → guarda el pago
       ↓
  ArchivoSocio → verifica que el socio existe
       ↓
  Actualiza estado de cuenta del socio
