📌 EXPLICACIÓN DE MÉTODOS escribirDisco() y leerDisco()
───────────────────────────────────────────────────────────────────────────

¿PARA QUÉ SE USAN?

Los métodos escribirDisco() y leerDisco() permiten que cada objeto pueda 
guardarse y leerse directamente desde el archivo binario en una posición 
específica.

• escribirDisco(int pos): bool
  - Escribe el objeto actual (this) en el archivo binario
  - Parámetro: posición en el archivo donde se escribirá
  - Retorna: true si la operación fue exitosa, false si falló
  - Usa fopen con modo "rb+" (lectura/escritura binaria)

• leerDisco(int pos): bool
  - Lee datos desde el archivo binario y los carga en el objeto actual
  - Parámetro: posición en el archivo desde donde se leerá
  - Retorna: true si la operación fue exitosa, false si falló
  - Usa fopen con modo "rb" (solo lectura binaria)

VENTAJAS:
- Cada objeto puede persistirse a sí mismo
- Acceso directo a cualquier registro por posición
- Separación de responsabilidades (objeto vs archivo)
